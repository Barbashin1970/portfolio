# Эффекты React Bits

Компоненты взяты из [React Bits](https://reactbits.dev) — реестр `<Имя>-TS-TW`,
снято 2026-10-26 — и адаптированы под сайт. Лицензия — MIT + Commons Clause, текст
в [LICENSE](LICENSE) рядом: в составе сайта использовать можно, продавать или
раздавать сами компоненты нельзя. Лицензия сайта на эти файлы не распространяется.

| Файл | Исходник | Что изменено |
|---|---|---|
| `SplitText.ts` | SplitText | компонент заменён функцией `splitReveal` для общего таймлайна hero; текст не прячется до загрузки шрифтов — его отдаёт предсборка (Р-22); эффекты, повторы и наведение убраны; параметры — из `motion/tokens.ts` |
| `Magnet.tsx` | Magnet | настройки пишутся в ref после рендера, а не во время него (правило `react-hooks/refs`); пружина и зона притяжения — из `motion/tokens.ts` |
| `Particles.tsx` | Particles | то же с ref; длительность появления — параметр, значение из `motion/tokens.ts`; `onReady` после первого кадра — по нему hero гасит статичный SVG |

Что осталось как было: у Particles — чистый WebGL2 без зависимостей, связи между
точками, пауза вне экрана и на скрытой вкладке, `loseContext` при размонтировании,
reduced-motion. У Magnet — общая пружина, тач и reduced-motion выключают эффект.
