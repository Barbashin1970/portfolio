### Рендеринг и публикация

```
vite build                          → dist/client (ассеты, шаблон index.html)
vite build --ssr src/entry-server   → dist/server (renderToString для ru и en)
node scripts/prerender.mjs          → dist/client/index.html      (ru)
                                      dist/client/en/index.html   (en)
                                      dist/client/404.html        (noindex)
                                      sitemap.xml, robots.txt, .nojekyll
GitHub Actions на push в main       → configure-pages → upload-pages-artifact (dist/client) → deploy-pages
```

- В браузере — `hydrateRoot`. GSAP, Lenis и WebGL запускаются только в эффектах,
  поэтому серверная сборка их не трогает.
- **Адрес:** репозиторий `portfolio` публикуется на
  `https://barbashin1970.github.io/portfolio/`, путь различает регистр. Vite `base`
  (`/portfolio/`) берём из имени репозитория в workflow, поэтому обе страницы и ассеты
  получают верную приставку.
- Роутер не нужен. Переключатель языка — обычная ссылка между двумя страницами.
- **Как Pages обходится с адресами** (замер навыка `publish-github-pages` на PROMPT-Professor):
  несуществующий адрес — 404 с нашей `404.html`, адрес без слэша — 301 на адрес со слэшем.
  Правил переадресации на Pages нет, и сплошного rewrite, который дал бы soft 404,
  не будет тоже.

### Анимационная система

- **Константы** в `src/motion/tokens.ts`: easing, длительности и шаги stagger
  (раздел 3). Чисел внутри компонентов нет.
- **Lenis ↔ GSAP — ровно по брифу:** `lenis.on('scroll', ScrollTrigger.update)`,
  `gsap.ticker.add((t) => lenis.raf(t * 1000))`, `gsap.ticker.lagSmoothing(0)`.
  Собственный цикл Lenis (`autoRaf`) выключен, второго сглаживания нет. После каждого
  изменения вёрстки — фильтр каталога, загрузка шрифтов — вызываем `ScrollTrigger.refresh()`.
- **`gsap.matchMedia()`** с двумя условиями: `isDesktop` и `reduceMotion`. Пин
  и горизонталь работают только на десктопе без reduced-motion. При reduced-motion
  Lenis не создаётся, WebGL не грузится, блоки появляются без движения.
- **Анимируем только transform и opacity.** Поэтому не берём BlurText (он анимирует
  `filter`), а CountUp понадобится позже, вместе с цифрами, и будет свой, на GSAP:
  версия React Bits тянет `motion`.
- **Освобождение ресурсов:** `useGSAP` сам откатывает твины и ScrollTrigger при
  размонтировании; `lenis.destroy()`; у WebGL-фона React Bits уже есть `loseContext`,
  пауза вне экрана и на скрытой вкладке.
- **Якоря** (`motion/anchors.ts`). У секций `scroll-margin-top: var(--header-h)`, и Lenis 1.3
  вычитает его из цели сам — поэтому `lenis.scrollTo(el)` без `offset`, иначе поправка
  двойная. Перед переходом — `ScrollTrigger.refresh()` и `lenis.resize()`: после фильтра
  каталога предел прокрутки Lenis устаревает. Без Lenis — `scrollIntoView`. Проверяем
  на самой нижней секции, «Контакте», а не на первой (урок `accordion-scroll-lands-on-wrong-section`).

### Производительность

- **JS на первую загрузку — не больше 170 КБ gzip.** Это оценка, сверяем в фазе 1
  по отчёту сборки. WebGL-фон вынесен в отдельный чанк: грузится после `load`
  в `requestIdleCallback` и только на десктопе.
- **Заголовок hero.** На телефоне он проявляется CSS-анимацией по словам: слова
  размечены при предсборке, и LCP не ждёт JavaScript. SplitText работает на десктопе.
  Иначе текст сначала виден, потом прячется ради анимации, и мобильный LCP падает.
- **Шрифты.** Три вариативных woff2. Кириллицу заголовочного и текстового шрифтов
  предзагружаем, `font-display: swap`, у запасного шрифта `size-adjust` против
  сдвига вёрстки. Google Fonts не подключаем: IP посетителей не уходит третьей стороне.
- **Кэш.** Pages отдаёт всё с `cache-control: max-age=600`, и это не настраивается.
  У ассетов хеш в имени, так что старый код не залипнет. На оценку Lighthouse это
  не влияет: кэш-политика там диагностика, а не метрика, и замер идёт с холодным кэшем.

### SEO и доступность

- У каждой страницы: title, description, canonical, hreflang (ru, en, x-default),
  Open Graph с картинкой 1200×630 на свой язык, JSON-LD Person (только подтверждённые
  поля; фото Олега для `image` уже есть — `media/oleg.webp`, Р-52), sitemap с альтернативами,
  robots.txt.
- `translate="no"` и `<meta name="google" content="notranslate">`, у `<html>` атрибут
  `lang` по языку страницы. Браузерный переводчик ломает DOM React (урок
  `browser-translator-breaks-react-dom`), а свой EN у сайта есть.
- Разметка: один `h1`; секции с `aria-labelledby`; видимый фокус (циан, 2 px с отступом);
  в доступном имени ссылки «Открыть демо» стоит название проекта. Фокус клавиатуры
  на карточке горизонтальной галереи прокручивает страницу к ней.

Ловушка, которую закрывает `--on-accent`: белый текст на `#FF6B35` даёт только 2,84 —
это провал AA. Поэтому кнопка — с тёмным текстом в обеих темах. До 2026-10-27 светлая
тема брала `#C2410C` с белым текстом, и Олег увидел кнопки «красными» (Р-41): теперь
заливка одна — морковная. Морковь текстом на бумаге — 2,6, поэтому слово-акцент
в заголовке берёт `--accent-ink` (`#EA580C`, 3,3 — AA для крупного текста). Акцент —
для действий и одного выделенного слова в заголовке. Циан — для данных, узлов графа и фокуса.
Градиентов «для красоты» нет.

### Типографика

| Роль | Шрифт | Размер | Детали |
|---|---|---|---|
| Заголовки | Geologica (вариативный: вес, резкость SHRP) | H1 `clamp(2rem, 10vw, 5.5rem)` — потолок снижен с 6,5rem под заголовок Р-26, H2 `clamp(2rem, 1.3rem + 3vw, 4rem)` | вес 650–750, межбуквенный −0,03em, высота строки 0,95–1,05 |

| Метки, стек | JetBrains Mono | 13 px, прописные, разрядка 0,08em | только короткие подписи |

Кириллица есть у всех трёх. Geologica — нормальной ширины, и всё же типограф склеивает
«до работающего» в неразрывный кусок около 8,3 em. Поэтому размер H1 идёт от ширины
экрана (10vw): кусок помещается и на 320 px (проверено в макете на 320 и 1440 px).
С прежним `clamp(2.75rem, …)` на 375 px слово обрезалось. Для русских текстов нужен типограф:
неразрывный пробел после коротких слов и перед тире, неразрывный дефис в «ИИ‑…» (Р-10).

### Сетка, отступы, радиусы

Контейнер — до 1280 px, поля `clamp(1rem, 4vw, 2.5rem)`; вертикальный ритм секций —
`clamp(6rem, 4rem + 8vw, 11rem)`; шаг отступов кратен 4 px. Радиусы: 12 px у кнопок
и полей, 24 px у карточек. У стеклянных поверхностей — граница 1 px `--border` и мягкое
свечение акцентом только на hover.

## 6. Риски и чем закрываем

| Риск | Что делаем |
|---|---|
| Внутреннее — личная инфраструктура, внутренние адреса — окажется в открытом репозитории или его истории | внутренняя опись — только в `.private/` (в `.gitignore`); сторож `check-private` по списку строк оттуда — до первого коммита и в каждой фазе (урок `private-repo-made-public-leaks-history`) |
| Почта автора попадёт в историю открытого репозитория | вопрос 9: noreply-адрес GitHub для этого репозитория |
| Код React Bits без уведомления об авторстве | `LICENSE` React Bits рядом с компонентами, исключение в нашей лицензии |
| Неверный адрес на Pages из-за регистра или приставки | `base` из имени репозитория в workflow; проверка на живом сайте командой |
| Интро заголовка тормозит мобильный LCP | CSS-появление на телефоне, SplitText только на десктопе |
| Пин съезжает при переходе по якорю | `scroll-margin-top` у секций (Lenis вычитает его сам), `refresh()` и `lenis.resize()` перед переходом; проверка на нижней секции — `check-layout` |
| Переводчик ломает React | `translate="no"`, синхронный `lang` |
| Streamlit усыпляет демо safety | на карточке пометка «демо засыпает без посетителей…»; скриншот снимается после пробуждения |
| TypeScript 7 ломает линтер | закрепляем 6.0.x, пока typescript-eslint не поддержит 7 |
