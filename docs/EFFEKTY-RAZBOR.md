# Разбор: аудит эффектов

Шаг 1 цикла SKICODING: карта до кода. Дата: 2026-10-27. Основание — просьба Олега:
«проведи аудит эффектов и если как дизайнер ты видишь, что нужно добавить эффекты, то
реализуй — тут у нас демо всех наших возможностей».

Рамка — договорённость 5, её не нарушаем: один сильный эффект на секцию; easing
и длительности — из `src/motion/tokens.ts`; анимируются только transform и opacity;
WebGL — один и только в hero; очистка через `useGSAP`; при reduced-motion — без пина,
Lenis и WebGL; на телефоне — без пина и тяжёлого фона.

## Фаза Г: заголовки секций по строкам (разрешено Олегом)

Олег 2026-10-27 на вопрос о маске-проявлении заголовков: «да — это красиво». Это исключение
из договорённости 5: у заголовков секций второй эффект поверх сильного эффекта секции (Р-51).

| Что | Как | Проверка |
|---|---|---|
| Заголовки секций ниже первого экрана поднимаются по строкам из-под маски | SplitText по строкам с маской после загрузки шрифтов; при смене ширины режется заново (autoSplit) и пересобирает анимацию; только transform; при reduced-motion заголовки не режутся | `check-layout`: на экранах с движением строки есть, после перехода к «Контакту» все строки выше низа экрана на месте; при reduced-motion строк нет |

Спор с React за текст (как у H1, Р-22) здесь не мешает: тексты заголовков на странице
не меняются, а SplitText оставляет заголовку `aria-label` с исходным текстом.
