# Разбор фазы 1 — каркас и hero

Шаг 1 цикла SKICODING: карта до кода. Дата: 2026-10-26. Основание — план фазы 0
([PLAN.md](PLAN.md), §5) и «продолжай» Олега от 2026-10-26.

## Сводка

1. **Кода сайта нет**, проверок нет. Фаза 1 ставит каркас и первый экран: hero
   с заголовком, подзаголовком, двумя кнопками и живым фоном. Готовность — семь ворот.
2. **Node 22.** vitest 5 требует Node ≥ 22.12, а локально стоял 20.20.2. Олег
   распорядился обновиться: через nvm поставлен 22.23.4, он же по умолчанию; в проекте
   `.nvmrc` = 22 (Р-21).
3. **React Bits оказался другим, чем записано в плане.** Particles написан на чистом
   WebGL2, без зависимостей; связи между точками у него встроенные (`connections`),
   пауза вне экрана и `loseContext` есть. Р-07 подтверждается. А SplitText прячет текст
   (`visibility: hidden`), пока не загрузятся шрифты, — с предсборкой это невидимый H1
   в HTML. Поэтому SplitText адаптируем (Р-22).
4. **H1 не принадлежит React.** Разметку слов H1 готовит предсборка, React вставляет
   её строкой. На телефоне слова проявляются CSS-анимацией и LCP не ждёт JavaScript;
   на десктопе GSAP SplitText режет те же слова на буквы и не спорит с React за DOM.
5. **Откладываем:** переход по якорю (цели «Смотреть работы» ещё нет — она в фазе 2),
   `size-adjust` запасного шрифта (без замера CLS число — догадка), EN-страницу и SEO
   (фаза 3).
6. **Коммиты — после сторожа.** `git init` нужен сторожу, чтобы знать, что попадёт
   в репозиторий. По ходу фазы Олег попросил опубликовать репозиторий и сайт: сайт
   выкатывается на Pages уже с фазы 1 (Р-23).

```
src/i18n/ru.ts ─── тексты ────────────┐
src/motion/tokens.ts ── числа ────────┤
                                      ▼
          App: Header + Hero ── renderToString (entry-server)
                                      │
                    scripts/prerender.mjs: H1, title, description,
                    предзагрузка шрифтов, lang="ru"
                                      │
                                      ▼
                       dist/client/index.html  ◄── check-dist, check-private
                                      │
            браузер: скрипт до отрисовки (тема, класс intro)
                                      │
                       hydrateRoot ── SmoothScroll: Lenis ↔ gsap.ticker
                                      │
              ┌───────────────────────┴───────────────────────┐
     телефон / reduced-motion                              десктоп
     CSS-появление слов,                     таймлайн GSAP: SplitText по буквам,
     статичный SVG-граф,                     Magnet на кнопках; после load + idle —
     без Magnet и WebGL                      WebGL Particles со связями
```
