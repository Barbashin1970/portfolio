## Что в записи LEYKA

Запись — 55 с, 2940×1844. Просмотрена по кадрам: раз в 4 с целиком, отрезок 25–40 с —
раз в секунду, поле «Исполнитель» — 4 кадра в секунду.

| Секунды | Что видно | Решение |
|---|---|---|
| 0–4 | вход; на 4-й секунде — выбор аккаунта Google с двумя адресами | не берём |
| 8–22 | KPI центра, прогноз, общий план с полными именами ответственных | не берём |
| 24–29 | пустые «Витрина центра» и «Библиотека знаний» | не берём: пустой экран — плохая реклама |
| 29,2–32,5 | доска (у людей инициалы), открывается задача «Фоторезист»; с 31,25 с в поле «Исполнитель» — полное имя | берём, поле размыто |
| 32,6–34,6 | карточку прокручивают вверх и обратно — имя проезжает по экрану | вырезаем: карточка возвращается в то же положение, склейки не видно |
| 34,75–43,45 | задача «Фоторезист», доска, задача «Локобригады»; в поле «Исполнитель» — полное имя | берём, поле размыто |
| 44–55 | в комментарий набран тестовый текст; в конце — панель записи экрана macOS | не берём |

Карточки задач открываются и закрываются мгновенно: 36,3 → 36,4 с и 38,0 → 38,1 с.
Поле «Исполнитель» всё время стоит на месте, около y = 500 px исходника, поэтому хватает
неподвижного размытия на то время, пока открыта карточка.
